# リベアイコンメーカー

公開URL：**https://sns-icon-maker.pages.dev/**

リベシティとoviceで使うプロフィール画像を、同じ画像・構図から作成する非公式ツールです。画像はブラウザ内だけで処理し、サーバーへ送信しません。

## 機能

- JPG / PNG / WebPを選択またはドラッグ＆ドロップ（本ツールの読み込み上限20 MB）
- ドラッグ移動・ホイール・スライダー・微調整ボタンで位置と大きさを調整
- 位置と大きさのリセット
- 同じ構図・形で2サイズのPNGを保存
  - リベシティ用：500×500px、`profile_icon_s.png`
  - ovice用：200×200px、`profile_icon_ss.png`
- 四角・白背景（標準）と丸形・背景透過を共通設定
- 保存前に実際のPNG Blob容量を検査（2,000,000バイト以下）
- 読み込み・出力失敗の表示、二重出力の抑止
- 320px幅を含むレスポンシブ表示

## 使い方

1. 画像を選択します。
2. 円のガイド内に顔や文字が収まるよう、位置・大きさを調整します。
3. 保存する形を選びます。
4. 位置・大きさ・形を変えずに、リベシティ用とovice用の両方を保存します。
5. 保存した画像を確認してから、それぞれのプロフィールに設定します。

円・十字線・透明部分の市松模様はガイドであり、出力画像には入りません。四角の保存時は透明部分・余白を白にします。丸形の保存時は円外と画像の透明部分を透過で保持します。

## 公式仕様と本ツールの方針

2026年11月7日確認。

- [リベシティ公式FAQ](https://faq.libecity.com/articles/32a97b4ea36723f32d29a76e5c57a06ca11a84d5)：500×500pxを推奨。
- [ovice公式仕様表](https://help.ovice.com/hc/ja/articles/16134945119641)：アバター画像200×200px、JPG / PNG、2 MB。200pxが必須かどうかは明記されていません。
- [リベシティ内のoviceのルール](https://faq.libecity.com/articles/426ddbe6ed773be04f54d203a33e9077940a1488)：リベシティのプロフィールと同じ画像を設定することが必須です。

リベシティの対応形式・容量上限は現在のプロフィール編集画面では直接未確認です。本ツールの入力上限20 MBをリベシティの公式上限と混同しないでください。出力は共通でPNGを使用し、より小さいoviceの2 MB上限に合わせて実容量を検査します。MBは保守的に1,000,000バイトとして扱います。

公式ツールではなく、サービスの仕様変更による影響を受ける場合があります。

## 開発・検証

React / TypeScript / Vite / Tailwind CSS / Lucide Icons。元リポジトリの構成と公開URLを維持しています。

```sh
npm ci
npm test
npm run lint
npm run build
npm run dev
```

テスト実行にはTypeScriptの型除去をサポートするNode.js 22.18以降（検証は24.22.1）を使用してください。

`tests/icon-export.test.mjs`はサイズ・接尾辞・同一構図・背景・形式・入力上限・出力の2 MB境界とエンコード失敗を確認します。ブラウザでの操作・実PNG・小画面の検証結果は`QA.md`を参照してください。
